# Fontes de referência

## Quando usar cada galeria

| Situação | Fonte | Por quê |
|----------|-------|---------|
| Site, landing, portfólio, direção de página inteira | **Minimal Gallery** (obrigatória) | Composição completa, tipografia e atmosfera |
| UI de produto, dashboards, componentes, microinterações, animação de interface | **CollectUI** | Padrões de UI e motion, não só marketing |
| Seção de features em bento, cards densos, grid tipo Apple/SaaS | **BentoGrids** | Layouts bento curados |
| Qualquer footer | **Footer Design** | Hierarquia, colunas, densidade; preferir Editor's Choice |
| Página com várias seções | Minimal + fontes das seções | Ainda 2–4 refs no total |

Não abra todas as galerias por padrão — só as que batem com o brief.

## Minimal Gallery — https://minimal.gallery

**Usar quando:** direção geral de website, landing ou portfólio.

Entradas em `/site/<slug>/`.

| Uso | URL |
|-----|-----|
| Home | https://minimal.gallery |
| Busca | https://minimal.gallery/?s=`<termo>` |

## CollectUI — https://collectui.com

**Usar quando:** UI, interfaces, animação de produto, padrões de componente — não só a “cara” do marketing site.

| Uso | URL |
|-----|-----|
| Home / feed | https://collectui.com |

Se o trabalho for uma página completa, combine com Minimal Gallery.

---

## BentoGrids — https://bentogrids.com

**Usar quando:** seções bento, feature grids, cards densos.

| Uso | URL |
|-----|-----|
| Home / Discover | https://bentogrids.com |

Filtros: categoria (Discover, Graphic Design, Web Design, Animation) e modo (All, Dark, Light). Prefira Web Design para seções de site; Animation quando o brief pedir motion no grid.

---

## Footer Design — https://footer.design

**Usar quando:** qualquer footer.

| Uso | URL |
|-----|-----|
| Home / gallery | https://footer.design |

Prefira Editor's Choice. Extraia hierarquia, colunas, densidade tipográfica, links vs. marca e legal/social — sem copiar conteúdo.
